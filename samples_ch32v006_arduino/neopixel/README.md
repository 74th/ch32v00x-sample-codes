# neopixel（Arduino Core CH32、CH32V006F8P6）

CH32V002 版と同じソース（`CH32VM00X` 分岐の nop 数。006 専用の調整はしていない）。データピン PC6。
- 観測: 006 実機で Pico の WS2812 デコーダが既知のバイト列（6 LED×3 バイト）を復号、不正パルスなし。バイト境界の L0 は 1280 ns で、002 と同一の機械語・同一の測定値のため 002 の上限 1300 ns を適用（規格の 1000 ns は超える）。[ログ](../../okf/log/2026-11-08-1636-ch32v006-arduino-batch2.md)
- **実発光と WS2812 規格適合は未確認**。
