# Spec Delta

## MODIFIED Requirements

### Requirement: HIL対象デバイスの明示選択

テストランナーは、HILの対象デバイスを利用者が明示選択でき、選択したデバイスに対応するソース（検証済みの共通ソースを含む）、設定、ビルドターゲット、期待型番だけを使って実行しなければならない（SHALL）。

#### Scenario: CH32V002を選択してHILを実行する
- **WHEN** 利用者がCH32V002を対象デバイスとしてHILを実行する
- **THEN** CH32V002用のサンプルと設定が使われ、開始時に対象デバイスと破壊的影響が表示され、結果に対象デバイスが記録される

#### Scenario: デバイスを指定しない
- **WHEN** 利用者が対象デバイスを指定せずにHILを実行する
- **THEN** 従来どおりCH32V003を対象とし、既存のCH32V003用コマンドの結果は変わらない

#### Scenario: 選択デバイスに未対応のテスト
- **WHEN** 選択したデバイス向けのサンプルまたは設定が存在しない、またはマトリクスで対象外とされている
- **THEN** そのテストは理由付きでskipされ、成功として報告されない

#### Scenario: 不明なデバイスを指定する
- **WHEN** 利用者が対応していないデバイス名を指定する
- **THEN** テストランナーは実機操作の前に設定エラーとして停止する

#### Scenario: CH32V006を選択してHILを実行する
- **WHEN** `--hil-device ch32v006` でch32fun HILを実行する
- **THEN** CH32V006F8P6の設定・マトリクス、CH32V006ビルドターゲット、CH32V006の期待識別値を使う
- **AND** 共通化成立後はCH32V002と共通のソース配置を使い、結果にはデバイス・型番・フレームワーク・ビルドターゲット・ソース配置・成果物識別情報を記録する

#### Scenario: 選択デバイスと設定型番が食い違う
- **WHEN** CH32V006を選択してCH32V002のHIL設定を渡す、またはその逆を行う
- **THEN** Pico/DUTの実機操作を始める前に設定エラーで停止する

#### Scenario: CH32V006の未対応フレームワークを選択する
- **WHEN** CH32V006でch32fun・arduino・wch以外の未対応フレームワークを選択する
- **THEN** 実機操作の前に未対応の組み合わせとして停止し、ch32fun共通ソースへ暗黙に置き換えない

#### Scenario: CH32V006のArduinoまたはWCHを選択する
- **WHEN** CH32V006とarduinoまたはwchの組み合わせを選択する
- **THEN** CH32V006F8P6の設定と選択フレームワーク専用のサンプル・マトリクスを使い、ch32funのソースや成果物へ暗黙に置き換えない
- **AND** flash前にCH32V006の検出と識別領域の型番0x006を確認し、書き込み後は全量readback一致を必須にする

### Requirement: HILサンプルのフレームワーク選択

テストランナーは、HILで使うサンプルのフレームワーク（ch32fun、arduinoまたはwch）を利用者が明示選択でき、選択したフレームワークとデバイスのサンプル・マトリクスだけを使って実行しなければならない（SHALL）。

#### Scenario: フレームワークを指定しない
- **WHEN** 利用者がフレームワークを指定せずにHILを実行する
- **THEN** 従来どおりch32funサンプルが使われ、既存コマンドの結果は変わらない

#### Scenario: Arduinoを選択してHILを実行する
- **WHEN** 利用者がarduinoフレームワークを選択してHILを実行する
- **THEN** `samples_<device>_arduino/` のサンプルとArduino用マトリクスが使われ、結果に対象デバイスとフレームワークが記録される

#### Scenario: 選択したフレームワークにサンプルがない
- **WHEN** 選択したフレームワークとデバイスの組にテスト対象のサンプルがない、またはマトリクスで対象外とされている
- **THEN** そのテストは理由付きでskipされ、成功として報告されない

#### Scenario: 不明なフレームワークを指定する
- **WHEN** 利用者が対応していないフレームワーク名を指定する
- **THEN** テストランナーは実機操作の前に設定エラーとして停止する

#### Scenario: WCHを選択してHILを実行する
- **WHEN** 利用者がwchフレームワークを選択してHILを実行する
- **THEN** `samples_<device>_wch/` のサンプルとWCH専用マトリクスを使用し、結果に対象型番・フレームワーク・ソース配置・SDK revision・成果物hashを記録する

#### Scenario: CH32V006のフレームワーク別結果を保存する
- **WHEN** CH32V006でarduinoとwchのHIL結果を保存する
- **THEN** デバイス・フレームワーク・サンプル・variant・実行を区別できる保存先を使用し、同名サンプルの別フレームワークの結果を上書きしない
- **AND** Arduino結果にはcore・FQBN・ライブラリ版、WCH結果にはSDK・コンパイラ・メモリ設定を特定する情報を含める
