# WCH公式SDK pwm（CH32V003）

作業日時: 2026-11-08 01:16 JST（ホストdateで確認、記録は実測直後）。

## 目的・条件
タスク2.8。CH32V003、固定minichlink、Pico fw v2（GPIO_PULSE）、既存配線PD2→GP14、PC4→GP15（各1 kΩ）。SDK 4e1b7437、WCH GCC 15.2.0。

## 実行
```sh
uv run pytest --hil --hil-framework wch tests/hil/wch/test_pwm.py -x -q
```

## 結果（実測）
- 試行1〜3: 期待周期の判定で失敗。k=32付近（255/256）のLow幅が短すぎ、Picoが周期235 µsなどと誤測定。
- 判定条件の見直しを繰り返した（分解不能判定: High<2 µs、Low<3 µs、duty範囲15〜95 %、PD2の最低読み数、取得窓を36組≒2.2 sへ）。この間、`period_us=33/43/86/22`などの誤測定で数回失敗。
- 最終条件で12回連続成功。PD2は複数のduty段階（約17〜73 %）、PC4はランプ読みと常時High。
- 除外はPico（GPIO_PULSE）の1 µs分解能・エッジ取りこぼしに起因し、DUT出力の不具合ではないと判断した根拠は、成功する実行で他の読みが一貫して10〜11 µsであること。ただし最終条件は失敗実行を見て調整したもので、条件が測定の緩和であることはREADMEに明記した。

## 未確認
オシロスコープでの93.75 kHz・デューティ精度、ランプ方向（up/down）とUARTの対応、PC4の詳細な段階。
