# WS2812 helper サンプルの HIL（verify-ch32fun-extralibs-with-pico タスク 6.1〜6.3）

- 実行日時（実測）: 2026-11-07 20:23〜20:27 JST（シェルの `date`）。記録は 20:28 頃。
- 目的: 固定 submodule の `extralibs/ws2812b_dma_spi_led_driver.h`（SPI1 + DMA、PC6）を使う DUT サンプルが送る WS2812 信号を、Pico のデコードで受けて、helper のソースから導いた期待バイト列と照合する。
- 条件: CH32V003F4P6、固定配線 PC6–GP7（1 kΩ）。Pico は GP19→GP20 の loopback 配線が接続されたまま（ユーザー申告）。submodule `b28d285`。電圧は未実測。
- サンプル: `samples_ch32v003_ch32fun/ws2812_spi/`（`WSGRB`、6 LED、固定色、100 ms ごとに送信）。map に book-code への参照なし（実測）。FLASH 1220 B。
- 期待値: helper の `WSGRB` 分岐（`ptr[k] = bitquartets[(ledval24bit>>S)&0xf]`）をソースから機械的に読み取り（`ch32hil/expected.py`）、コールバック値 `R | G<<8 | B<<16` から導く。ワイヤ上の順は G, R, B。期待 `00ffa55a0180ff000ff033cc55aa7e8118c3`（18 バイト）。book の元サンプルのコメント（`red | blue<<8 | green<<16`）に従うと B が先頭になる点は、ソースを読んだだけの観察で、実際の LED の色は未確認。

## 結果（実測）

- HIL: 最終構成で 3 回連続 passed（約 1.9 秒/回）。拡張ライブラリ HIL の一括実行でも passed（3 passed、1 xfailed は SSD1306 の 1 MHz）。判定内容: `rx` が期待バイト列と一致、`bad_pulses=0`、`bits=144`。デコード幅 `t0h_ns=304`、`t1h_ns=976`（Pico 単体の自己検証と同じ値）。

## 経緯と発見（時系列）

1. 最初の実行は 3 回とも `ERR WS2812 frame_too_long expected=144`。期待より長い 96 バイトを指定して確認すると `frame_bits=145`、先頭 18 バイトは期待値と完全一致。
2. 余分な 1 パルスを調べるため、ビット数不一致の応答に `bad_pulses`、端数ビット、最後のパルス幅を追加（Pico firmware 更新・再書き込み）。145 番目のパルスは範囲外（`bad_pulses=1`）で、幅は計測上限（約 1.05 ms）に飽和していた。
3. 解釈（実測値から導いた推定。DUT 側の波形を別の計測器で見てはいない）: DUT の信号線はフレームの間 High のまま待機し、次のフレーム先頭のリセット（Low）で初めて下がる。Pico にはデータの後ろに長い High が 1 個付いて見える。helper のコメントには「line high にしてもよい」と書かれているが、コードは 0 を書いており、待機レベルが High になる理由は未調査。
4. 対応: Pico のデコードを次のように変更した。(a) 最後のパルスが 100 µs を超える High なら、データではなく待機 High（`idle_high=1`）として扱い、ビット数に数えない。(b) フレーム終端マーカーを見つけた時点で取り込みを止める（フレームの後ろに 1 パルス付く場合と付かない場合の両方に対応するため、DMA は `2×ビット数+2` 語を確保）。(c) ホスト単体テストに待機 High、境界（100 µs ちょうど）、フレーム内の広いパルスの 3 項目を追加。
5. 変更後に `ws2812_selftest.py` を再実行して PASS（Pico 単体の自己検証に退行なし）。DUT の HIL は 3 回連続 passed。

## 判定範囲と未確認

- 確認したこと: helper が送る 18 バイトが、ソースから導いた期待バイト列と一致して Pico に届き、各パルスが範囲内だった。DUT がフレームの後ろに長い High を残す挙動の存在。
- 未確認: 実 LED の発光・色、WS2812 の規格上のタイミング適合、High 待機が LED のラッチに与える影響、待機 High の原因、1 kΩ 経由の波形の質、Pico の測定偏り（約 −32 ns、原因未切り分け）、複数リセットを跨ぐ再現性（各回で build・flash・reset を実施した 3 回＋全体 1 回のみ）。
