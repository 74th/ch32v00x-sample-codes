# helper 検証 3 サンプルの CH32V002 HIL（verify-ch32fun-extralibs-with-pico タスク 7.2）

- 実行日時（実測）: 2026-11-07 20:33〜20:35 JST（シェルの `date`）。記録は 20:36 頃。
- 目的: CH32V003 で確認済みの helper 検証 3 サンプル（`i2c_slave_helper`、`ssd1306_i2c`、`ws2812_spi`）を CH32V002F4P6 へ移植して実機で確認する。
- 条件: DUT の差し替えはユーザーが実施（ユーザー申告。実施時刻・電圧測定値は未記録）。固定配線は変更なし。Pico は GP19→GP20 の loopback 配線が接続されたまま（ユーザー申告）。submodule `b28d285`、ベース `a409839`。電圧は未実測。
- 移植の差分と RM 照合: `okf/peripherals/ch32v002-port-differences.md`（I2C helper 2 件は `-DAPB1PRSTR=PB1PRSTR` が必要。helper は未変更）。

## 実行と結果（実測）

1. `./scripts/ch32fun.sh flash ch32v002`: `Part Type: 00-20-06-20`、`Image written.`、`FLASH OK (runtime unverified)`。出力の末尾 8 行のみ確認。識別領域 `0x1ffff704` の照合は HIL の flash 段階（flash 前）で行われ、全 HIL が flash 段階を通過した。
2. `uv run pytest --hil --hil-device ch32v002 -m 'hil and extralibs' tests/hil/test_extralibs.py`: 3 回とも 3 passed、1 xfailed（12.6〜12.9 秒）。
   - `i2c_slave_helper`: V003 と同じ期待値（write count 2、reg 0x10、len 4、read count 13、last read reg 3）で passed。
   - `ssd1306_i2c`（100 kHz）: フレーム CRC が V003 と同じホスト生成の期待値と一致して passed。helper 既定の 1 MHz は V003 と同様に xfail（Pico が受信できず。原因は未切り分けのまま）。
   - `ws2812_spi`: 期待バイト列と一致、範囲外パルス 0、`t0h_ns=304`、`t1h_ns=976`、`idle_high=1`。V003 と同じ値で、SPI の 3 MHz は V002 でも成立している（`HSCR` を設定しない V002 でも BR=3 で同じ幅）。
3. V002 での全 HIL（既存＋extralibs）: `uv run pytest --hil --hil-device ch32v002`: 215 passed、1 xfailed（60 秒）。

## 判定範囲と未確認

- 確認したこと: CH32V003 と同じ条件で、Pico が観測した I2C/SSD1306/WS2812 の内容が期待どおりだった。
- 未確認: 実 OLED/LED、1 MHz の I2C（V003 と同じ）、待機 High の原因、電圧・波形、複数回リセットを跨ぐ再現性（各回で build・flash・reset を実施した 3 回＋全体 1 回）、DUT 差し替え時の電圧。
- DUT は CH32V002 のまま。CH32V003 へ戻す差し替え（ユーザーの手作業）と 8.2 の回帰確認は未実施。
