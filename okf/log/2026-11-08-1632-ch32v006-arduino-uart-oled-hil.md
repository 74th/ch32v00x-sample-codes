# CH32V006 Arduino uart（CO2 センサー模擬＋OLED 模擬）の HIL（タスク 4.5 の一部）

- 作業日時: 2026-11-08 16:32:15〜16:33:15 JST（`date` で確認）。記録は 16:36 JST 頃。
- 対象: CH32V006F8P6（ユーザー申告で差し替え済み）。固定配線、電圧は未測定。F8P6=F8P7 は前 change の仮定のまま。
- 方法: [003 での手順確認](2026-11-08-1629-ch32v003-arduino-uart-oled.md)と同じ（Pico がセンサー役の応答を DUT の受信バッファへ送り、直後に INIT なしで SSD1306 模擬を 1.5 s 取り込む。最終ページは確定遅れのため比較外）。006 は書籍のスケッチ（128x32、変更なし）。

## 結果（実測）
- `tests/hil/arduino/test_uart.py::test_arduino_uart_co2_to_oled`: 3 回連続で passed（各 10.15 s）。識別 `chip_id=0x00630620`（0x006）、全量 readback 一致、read command 捕捉（`ff0186…79`）、取り込み data=384 B（ページ 0〜2）、判定はページ 0〜2 がホスト描画の「loop: 2 / co2 : 1234 ppm」と一致。
- 感度確認: 送る値を 1235 ppm にすると失敗（記録は下記）。テスト本体は元に戻した。
- ビルド: Flash 15,476 B / 63,488 B、RAM 1,140 B。
- 同時に実行した PWM（必須）は引き続き失敗（PC4 無信号、前ログと同じ症状）。
