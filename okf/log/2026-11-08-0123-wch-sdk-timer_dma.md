# WCH公式SDK timer_dma（CH32V003、4桁7セグメント走査）

作業日時: 2026-11-08 01:23 JST（ホストdateで確認、記録は実測直後）。

## 目的・条件
タスク2.10。CH32V003、固定minichlink、Pico fw v2（GPIO_SAMPLE）、既存配線。観測ピン: PD6→GP8、PD5→GP9、PC0→GP5、PC4→GP15、PD2→GP14、PC7→GP4、PC5→GP6、PC6→GP7（各1 kΩ）。SDK 4e1b7437、WCH GCC 15.2.0。7セグメント表示器は接続していない。

## 実行
```sh
uv run pytest --hil --hil-framework wch tests/hil/wch/test_timer_dma.py -x -q
```

## 結果（実測）
- 試行1〜3（1 ms間隔）: 一部ピンで期待比率から外れ失敗。PC7はrun数2（走査と同期してほぼ固定値、エイリアシング）。間隔を1170 µsに変更。
- 試行4〜9（1.17 ms間隔）: PD6だけが0.56〜0.73と低く2/6失敗。別プローブ（間隔1170/1237/1500/2111 µs、各3回）ではPD6も0.74〜0.76で安定。原因は、リセット直後の最初の測定に走査開始前（約100 ms）の区間が含まれること。リセット後1秒待つように修正。
- 試行10以降: 11回連続成功。全ピンのHigh比率が期待値の約0.02以内（SEL1=0.757、SEL2=0.757、SEL4=0.753、SA=0.743、SD=0.747、SE=0.517、SF=0.257、SG=0.497）。許容を0.15→0.10に締めても成功。
