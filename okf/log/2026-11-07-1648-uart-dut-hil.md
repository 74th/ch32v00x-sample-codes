# CH32V003 UART HIL

- 作業日時: 2026-11-07 16:47–16:48 JST。記録は作業後。
- 目的: 独立 loopback を通過した Pico UART の DUT モードで、標準 ch32fun UART エコーを build、flash、readback、送受信、timeout と cleanup まで確認する。
- 配線: ユーザー申告の配線案で CH32 PD5 TX→Pico GP9 RX、Pico GP8 TX→CH32 PD6 RX。GPIO 接続は `2026-11-07-1506-gpio-wiring-observation.md` で確認済み。Pico GP16–1 kΩ–GP17 の UART 自己試験は `2026-11-07-1640-pico-uart-dut-mode.md` を参照。電圧・抵抗値は今回独立測定していない。
- ツール: WCH-LinkE 2.22、固定 ch32fun `b28d285460ce052a179dba8f4a22c6f73ff8e328`、Pico SDK 2.2.0 `a1438dff1d38bd9c65dbd693f0e5db4b9ae91779`、TinyUSB `86ad6e56c1700e85f1c5678607a762cfe3aa2f47`、pytest 8.4.2、pyserial 3.5。
- ソース: 作業時点の未コミットツリー。実験後 SHA-256: `tests/hil/test_uart.py` `e3263fa130f2436f3d59603e371634a7d05b323d02b5c489dfb1f920a665d3a4`、`tests/hil/test_blink_and_read.py` `294abb47d2e9a4c72ee005c3101719c176c9faaec470d0246df6b6ae53772466`、DUT `uart/main.c` `d558a41058976acec4a2d04f15ce78ee62d5e735fd5ecd362b9bf30ffc46259a`、Pico `uart_fixture.c` `af4be466c5b5094fe30374c2b349ffce77405e664fe0b60617db13d6cffd4fad`。
- コマンド: `./scripts/ch32fun.sh flash ch32v003` で CH32V003 検出を確認後、`uv run pytest --hil -m 'hil and uart' tests/hil/test_uart.py -v -s --hil-port /dev/serial/by-id/usb-Raspberry_Pi_Pico_E661AC8863223539-if00`。改良後に同 HIL を再実行。
- 実測: 115200 baud、8N1。固定 minichlink が CH32V003 と書き込みを確認し、サイズ指定 readback が build したバイナリーと一致。UART の `00 55 a5 ff` と 0x00〜0x1f の32バイトはそれぞれ往復一致、UART error flags 0。送信せず受信を待つ要求は `ERR TIMEOUT`。RESET_SAFE 後 GP5/8/9/10 は output=0、pull_up=0、pull_down=0。最終実行 1 passed。DUT は UART echo、Pico は v2 UART 対応版が残っている。
- 失敗: 想定外の失敗なし。受信 timeout は意図した負のケース。
- 未確認: フレーミング・parity エラー注入、他 baud/frame の DUT 通信、独立電圧・波形測定、USB 物理抜去。loopback は校正済み計測ではない。
