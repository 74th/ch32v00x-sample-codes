## 目的・条件
タスク2.6。CH32V003、固定minichlink、Pico fw v2（I2C_MASTER/I2C_PROBE）、既存配線PC1↔GP10、PC2↔GP11（各220 Ω、4.7 kプルアップ）。SDK 4e1b7437、WCH GCC 15.2.0。

## 実行
```sh
uv run pytest --hil --hil-framework wch tests/hil/wch/test_i2c_slave.py -x -q   # 計4回
```

## 結果（実測）
- 1回目: repeated START項目の期待値の取り方が誤り（Pico応答の`rx`は読み出しデータ、`sent`フィールドは無い）で失敗。ポインタ設定・読み出し・書き込み・部分読みまでは成功していた。
- テストを修正し2〜4回目は3回連続で全項目成功（probe、読み書き、ポインタ更新、repeated START 3通り）。DUTのハング（SCL張り付き）なし。
