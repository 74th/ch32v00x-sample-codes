# WCH公式SDK adc_dma（CH32V003）

作業日時: 2026-11-08 01:00 JST（ホストdateで確認、記録は実測直後）。

## 目的・条件
タスク2.4。adcと同じ（CH32V003、PA1/PA2のRC、PD5→GP9）。SDK 4e1b7437、WCH GCC 15.2.0。

## 実行
```sh
uv run pytest --hil --hil-framework wch tests/hil/wch/test_adc_dma.py -x -q
externals/ch32fun/minichlink/minichlink -r + 0x40020008 16   # 参考: DMA1 CH1レジスタ読み出しの試行
```

## 結果（実測）
- HIL 1回で成功。値: x_high/y_low=810/43、x_low/y_high=205/950、both_low=0/0、x階段=[583,767,843]、y階段=[580,767,849]。
- minichlinkによるDMAレジスタ読み出し（0x40020008から16 B）は全て0。周辺レジスタは読めない（または停止後の値）と判断し、DMAの直接確認には使わなかった。
- `adc_buf`を非volatileのままにする検証は行っていない（volatileにして実装）。

## 未確認
DMAレジスタ値の実測、High保持値が単発adcより低い原因、絶対精度。
