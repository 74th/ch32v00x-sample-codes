## 執筆中に見つけたサンプル側の不整合（未修正。原稿では注記）

- WCH SDK の `adc/main.c`（002/006）冒頭コメントが 003 の説明（10-bit、校正）のまま。`hil/matrix_ch32v002_wch.json` の adc の criteria の文字列も 0..1023 の尺度のまま（試験コードは 12 ビットの尺度で判定）。
- WCH SDK の `timer_blink` の「1sec event」（実際は 500 ms）と、`timer_dma` の「10us」（PSC=480 で約 100 µs）のコメント。`timer_blink` のコメント「IPRIOR[8]」（実際は 256）。
- WCH SDK の `i2c_master` の `USE_REMAP 1` 分岐は、003 の定数 `GPIO_FullRemap_I2C1` のままで、ビルドできない見込み（未確認）。`i2c_slave` は `I2C_ClockSpeed` が 0 のまま `I2C_Init()` を呼んでいる。
- WCH SDK の `standby_wake`/`sleep_wake` のコメントと設定値が食い違っている（window 31 と 25、1 s と約 2 s）。
- ch32fun の `i2c_slave_helper` のコメント（読み出しの後も STOP を報告）が、1956 ログの実測の解釈と食い違っている。
- Arduino の `adc.ino` のコメント（0~1024）、`i2c_slave` の `on_request` の範囲判定（旧版の誤りが残り、範囲外を読む可能性）。
- 固定 ch32fun の `funAnalogInit()` は V00x でも EXTTRIG を立てていない（サンプルでは使っていない。未確認）。
