# WCH公式SDK uart（CH32V003、CO2センサー模擬）

作業日時: 2026-11-08 00:58 JST（ホストdateで確認、記録は実測直後）。

## 目的・条件
openspec change add-wch-sdk-peripheral-samples タスク2.2。CH32V003（WCH-LinkE 2.22、固定minichlink）、Pico firmware v2、既存固定配線PD5→GP9、PD6←GP8（各1 kΩ）。SDK 4e1b7437、WCH GCC 15.2.0。配線の物理再測定はしていない。

## 実行
```sh
uv run pytest tests/unit/test_wch_co2.py
uv run pytest --hil --hil-framework wch tests/hil/wch/test_uart.py -x -q
```

## 結果（実測）
- ホスト単体テスト9件成功（既知応答・checksum・ヘッダ異常）。
- HIL 1回目失敗: 自己校正コマンドが2回出た。`dut.reset`の前の`wait_ready`（minichlink -i）でDUTが再起動しており、さらにresetで再起動していた（probeで32 B取得: cmd,cmd,"timeout","start"）。テストをwait_ready直後にキャプチャする形に修正（DUTのバグではない）。
- HIL 2回目成功: 全phase成功（build/flash/全量readback、自己校正cmd一致、`start`、読み出しcmd一致、`CO2:  1234 ppm`、`invalid checksum`、`read timeout`）、uart_errors 0x0。

## 未確認
実センサー、PC0/PC1リマップ構成（治具で配線できない）、他baud。Pico応答のタイミングは1呼出内の送信で、センサーの実応答遅延は模擬していない。
