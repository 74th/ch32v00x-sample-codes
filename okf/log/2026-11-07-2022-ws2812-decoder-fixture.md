# WS2812 デコード治具の実装（verify-ch32fun-extralibs-with-pico タスク 5.1〜5.3）

- 実行日時（実測）: 2026-11-07 20:14〜20:22 JST（シェルの `date`）。記録は 20:22 頃。
- 目的: Pico が WS2812 信号を受けてバイト列にデコードする治具能力を追加する（DUT の NeoPixel helper の検証用）。
- 条件: 配線は I2C loopback（GP16–GP18 / GP17–GP19 と pull-up）のまま（ユーザー申告）。DUT 固定配線 PC6–GP7 は DUT 側が WS2812 を送らないサンプルが動作中。submodule `b28d285`、ベースは直前のコミット。

## 実装

- `ws2812_decode.pio`: 各パルスの High 幅（2 サイクル/カウント、125 MHz で 16 ns）と、Low 側の残カウント（50 µs の Low が続いたらマーカー `0xFFFFFFFF`）を、ビットごとに 2 語ずつ push する。
- `ws2812_classify.c/.h`: ハード非依存の分類（High 幅 190〜480 ns を 0、830〜1150 ns を 1、それ以外は範囲外としてカウント。閾値 655 ns で値を決める。中央値の幅を返す）。ホストの gcc で単体テスト 17 件。
- `ws2812_fixture.c`（解析と応答）、`ws2812_hw.c`（PIO1 + DMA、同期、SPI0 loopback 送信）。コマンド `WS2812_CAPTURE <pin 7|20> <bytes 3-96> <timeout_ms>`、`WS2812_SELFTEST <OK|BADWIDTH|TIMEOUT>`。
- 同期: 受信開始時に 200 µs Low が続いていればフレーム間と見なしてそのまま開始、そうでなければ最初のリセット間隔（マーカー）を待つ。

## 実行と結果

1. `uv run pytest -q tests/unit`: 191 passed（実測）。引数の範囲、短い/長いフレーム、範囲外パルス、タイムアウト、自己検証 3 モードの応答はスタブを使ったホスト試験で、実機の PIO/DMA/SPI は含まない。
2. Pico firmware: ビルド警告なし。
3. 最初に書き込んだ版は `WS2812_CAPTURE` で Pico が固まり、USB の書き込みがタイムアウトした（実測。クライアントが約 60 秒応答待ちで止まった）。原因（私の実装ミス）: RX FIFO を結合（`PIO_FIFO_JOIN_RX`）したため TX FIFO の深さが 0 になり、ゲート幅を渡す `pio_sm_put_blocking` が永久に待っていた。`picotool reboot -f -u` で BOOTSEL へ入れて復旧（ユーザーの物理操作は不要だった）。FIFO 結合をやめて再ビルド・再書き込み。
4. 修正後: `CAPS` に 2 コマンドが列挙され、DUT 配線のまま `WS2812_CAPTURE 7 18 50` と `... 20 18 50` を繰り返し実行して `ERR TIMEOUT ws2812 bits=0 safe=1`（約 0.05 秒）、`RESET_SAFE` OK（実測）。

## 5.2 実機の自己検証（追記、20:21 JST の実測）

- 配線: ユーザー申告で GP19→1 kΩ→GP20 の SPI 系配線へ切り替え済み（I2C loopback の pull-up は撤去）。配線自体は私は確認していない。
- `uv run python hardware/pico-tester/ws2812_selftest.py`: 1 回目で PASS。`WS2812_SELFTEST OK` を 3 回: 送信と受信が一致（`00ffa55a0180`、48 ビット、範囲外 0、`t0h_ns=304`、`t1h_ns=976`、実効 baud 2976190）。`BADWIDTH`: 範囲外 1 個を検出（`bad_pulses=1`、欠陥ビットは 1 と判定、`rx=80ffa55a0180`）。`TIMEOUT`: `words=0`。引数なし・不正モードは `ERR INVALID`。無信号の `WS2812_CAPTURE 20 6 50` は `ERR TIMEOUT`。GP7/19/20/21 は出力 0・pull なし。
- 観測: High 幅の測定値は理論値（336/1008 ns）より常に 32 ns（2 カウント）小さい。PIO ループ入口の遅れによる固定の偏りと推定（原因の切り分けはしていない）。分類範囲には収まる。
